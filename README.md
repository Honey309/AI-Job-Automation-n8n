# 🤖 AI Job Automation System (n8n)

This project automates job search and application using AI.

## 🚀 Features

* 📩 Reads job emails automatically
* 🧠 Classifies job vs spam
* 📊 Extracts role & company
* 📄 Matches with resume
* 📈 Calculates ATS score
* ✍️ Generates job application
* 📧 Creates Gmail draft

## 🛠 Tech Stack

* n8n (Automation)
* LLM API (Groq/OpenAI)
* Google Sheets
* Gmail API

## 📂 Files

* n8n-job-automation.json → Main workflow

## 💡 Use Case

Helps job seekers automate job tracking and application process.
